# Dynasty Showdown

⚔️ **Dynasty Showdown** is a 2D side-scrolling strategy battle game built with Unity, inspired by classic titles like *Age of War* and *Mirage War*.  

---

## 🎮 Game Type & Gameplay
- **Genre**: 2D Strategy / Battle / Auto-fight  
- **Gameplay**:
  - Players spend **gold** to summon units (Infantry, Cavalry, Mage).  
  - Units automatically march along the battlefield to attack the enemy base.  
  - The **enemy AI** adapts its strategy based on the player’s recent unit choices.  
  - Both bases have health bars; when one base reaches 0 HP, the game ends.  
  - Victory or defeat leads to a dedicated **Game Over scene** (Win / Lose).  

---

## 🛠️ Development Info
- **Engine**: Unity 2022.3.x  
- **Language**: C#  
- **Key Features**:
  - Unit summoning with cost & cooldown system  
  - Adaptive enemy AI logic  
  - Health bars and gold economy system  
  - Sound effects and background music  
  - Start menu and Game Over scenes
